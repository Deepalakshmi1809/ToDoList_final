# ToDoList

A modern Todo List application built using React and Ant Design.

## Features

- Add and manage tasks
- Mark tasks as completed
- Delete tasks
- Calendar view
- Dark mode
- Responsive design

## Technologies Used

- React
- Vite
- Ant Design
- JavaScript

## Getting Started

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```
